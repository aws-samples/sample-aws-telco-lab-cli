## Telco CLI 1.0.0 — first PyPI / semver release

This is the **first official versioned release** of **telcocli** on GitHub Releases and PyPI. Earlier development used the moving [`ci-build`](https://github.com/aws-samples/sample-aws-telco-lab-cli/releases/tag/ci-build) prerelease for snapshot wheels only.

### Highlights

- **Install:** `pip install telcocli` (requires Python 3.9+).
- **CLI:** `telcocli` entry point for AWS Telco Lab operations (Organizations, accounts, EC2 dedicated hosts, EKS, and related workflows as documented in the repo).
- **Artifacts:** This release attaches the **wheel** and **source distribution** built with `python -m build` and checked with `twine check`.
